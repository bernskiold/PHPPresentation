# 1.3.0

[Full Changelog](https://github.com/PHPOffice/PHPPresentation/compare/1.2.0...1.3.0)

## Enhancements
- `phpoffice/phpspreadsheet`: Allow version 5.0 by [@seanlynchwv](http://github.com/seanlynchwv) in [#879](https://github.com/PHPOffice/PHPPresentation/pull/879)
- New `AdvancedScatter` chart type with proper numeric X / Y axes, multiple series, duplicate X values across data points, configurable scatter style (`marker`, `lineMarker`, `smooth`, etc.), per-data-point coloring and `varyColors` support — matching PowerPoint's scatterChart capabilities. Read and write supported for the PowerPoint 2007 (.pptx) format.
- Sections: `PhpPresentation::createSection()`, `addSection()`, `getAllSections()`, `setAllSections()` and `getSectionOf()`, grouping slides under a name as PowerPoint's slide pane does. Read and write supported for the PowerPoint 2007 (.pptx) format.

## Bug fixes
- Fixed static analysis on PHP 8.0 to 8.6: PHPStan 1.x could not resolve the symbols of PHPUnit 13, so PHPStan 2.2 is used where PHP allows it. Ported from upstream [#897](https://github.com/PHPOffice/PHPPresentation/pull/897), [#1000](https://github.com/PHPOffice/PHPPresentation/pull/1000) and [#1005](https://github.com/PHPOffice/PHPPresentation/pull/1005).
- PowerPoint2007 Reader : Fixed a node taken out of a node list being treated as an element without checking that it is one.
